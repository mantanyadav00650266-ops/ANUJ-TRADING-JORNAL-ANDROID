# ANUJ Trading Journal — Android App

This is a real Android application wrapper around the V3 Trading Journal + AI Assistant + TradeZella-style Calendar. It runs locally inside an Android WebView and does not open Chrome.

## Build in Android Studio
Open this `android` folder as an Android Studio project and run the `app` configuration on a phone or emulator.

## Build APK from GitHub
Upload the `android` folder and workflow to a GitHub repository. Run **Actions → Build Android APK → Run workflow**. Download the `ANUJ-Trading-Journal-APK` artifact.

The aggressive bull/bear icon is included as the launcher icon.


## Aggressive icon included
The launcher icon is the neon green bull vs red bear design. It is wired in AndroidManifest.xml as @drawable/icon and included in all launcher density folders.
